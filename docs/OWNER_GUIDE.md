# Руководство владельца INSIDA

Сайт работает бесплатно на GitHub Pages. Сервера, базы данных и аккаунтов посетителей нет. Всё, что вы публикуете, лежит в вашем репозитории `viksylia-rgb/insida` на GitHub.

**Адрес сайта:** https://viksylia-rgb.github.io/insida/

---

## 1. Как редактировать сайт (Pages CMS)

1. Откройте **https://app.pagescms.org** и нажмите **Sign in with GitHub**.
2. Выберите репозиторий **insida**, ветку **main**.
3. Слева появятся разделы: «Статьи и термины», «Тесты», «Практики», «Программы», «Книжная полка», «Гайды», «Страницы и документы», «Настройки сайта», «Темы», «Вопросы и ответы».
4. Внесите изменения и нажмите **Save**.

**Ожидаемый результат:** через 2–4 минуты изменения появятся на сайте. Если не появились, обновите страницу с Ctrl+F5.

## 2. Как добавить статью

«Статьи и термины» → **Add an entry**:
- **Заголовок** и **Адрес страницы.** Адрес пишется латиницей через дефис, например `kak-perezhit-razluku`. Адрес задаётся один раз, потом его лучше не менять.
- **Формат**, **Тема**, **Теги**, **Краткое описание**.
- **Обложка:** загрузите фото. Пишите **описание обложки** для незрячих читателей.
- **Источники:** только реальные книги и статьи.
- **Текст:** пишите как в обычном редакторе (заголовки, списки, жирный, ссылки, картинки).
- Если это ваш настоящий текст, снимите галочку **«Демонстрационный материал»**.
- **Опубликовано:** выключите, чтобы сохранить черновик, который не будет виден на сайте.

## 3. Как добавить тест

«Тесты» → **Add an entry**:
1. **Шкалы** — то, что вы измеряете. Ключ пишется латиницей (`self`), название — по-русски («Самокритика»).
2. **Вопросы** → варианты ответа → **Баллы**: укажите ключ шкалы и число баллов.
3. **Ветвление** (необязательно): «Перейти к вопросу №».
4. **Правила результатов**: для каждой шкалы задайте диапазоны «от–до», чтобы каждый возможный балл попадал ровно в одно правило. Если ошибётесь, сайт не опубликуется, а в разделе **Actions** на GitHub будет написано, что исправить.

⚠️ Не называйте опросник диагностикой и не публикуйте известные клинические шкалы без проверки лицензии.

Проще всего начать с копии готового теста: откройте демо-тест и измените вопросы.

## 4. Фото, тексты главной, контакты

- **«Настройки сайта»:** заголовок и фото главной, ваше имя, история, фото, образование, миссия, соцсети, текст для чувствительных тем, сведения о продавце.
- **Фото** загружаются прямо в поле. Перед загрузкой сожмите до ~1600 px по ширине (например, на https://squoosh.app). Используйте только фото, на которые у вас есть права.
- **PDF для бесплатных гайдов:** поле «Файл» в карточке гайда.

## 5. Цвета и шрифты

На GitHub откройте файл `src/styles/tokens.css` и нажмите карандаш (Edit). Цвета собраны в начале файла, например `--c-rose: #c99fa7;`. Замените код цвета и нажмите **Commit changes**. Проверяйте контраст текста: https://webaim.org/resources/contrastchecker/ (не меньше 4.5:1).

## 6. Если сайт не обновился

Откройте репозиторий на GitHub → вкладка **Actions**:
- зелёная галочка — всё опубликовано;
- жёлтый кружок — публикация идёт;
- **красный крестик** — найдена ошибка. Нажмите на запуск, затем на шаг «Проверка контента»: там написано, в каком файле и поле проблема. Исправьте её в Pages CMS, и публикация запустится снова. Пока ошибка не исправлена, на сайте остаётся предыдущая рабочая версия.

## 7. Резервные копии

Каждое изменение сохраняется в истории GitHub, и любую прошлую версию можно вернуть. Для отдельной копии на компьютере: на странице репозитория **Code → Download ZIP** (раз в месяц).

## 8. Продажи

На сайте нет оплаты. У платного гайда укажите **«Ссылку для покупки у продавца»** (VK, Telegram) и статус **«Доступен / в продаже»**. До этого:
- проверьте с юристом оферту и договор с ИП;
- заполните «Сведения о продавце» в настройках.

См. [чек-лист](LAUNCH_CHECKLIST.md).

## 9. Свой домен (необязательно, платно)

Можно купить домен (например, `insida.ru`) и подключить его: Settings → Pages → Custom domain. Сайт будет открываться без `/insida` в адресе.
