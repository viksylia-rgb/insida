## 2. Бесплатный хостинг: лимиты и что делать при превышении

Данные проверены в ноябре 2026 года. Условия провайдеров меняются, поэтому **перепроверьте их перед запуском**. «Навсегда бесплатно» никто не гарантирует.

| Сервис | Лимит Free | Что будет при превышении | План действий |
|---|---|---|---|
| **Netlify Free** | 300 кредитов в месяц на всё: сборки, трафик, функции. Коммерческое использование разрешено | Все сайты аккаунта **ставятся на паузу** до следующего месяца | Страницы кэшируются на CDN (5 мин), картинки — на год. Следите за Usage в панели. При росте — Netlify Pro или переезд по Dockerfile |
| **Neon Free** | 100 CU-часов compute в месяц, около 0,5–1 ГБ данных, засыпает после 5 минут простоя | Запись в базу блокируется при превышении объёма; первый запрос после сна — с задержкой | Не храните тяжёлые файлы (лимиты загрузки: 4 МБ на фото, 5 МБ на PDF). Объём видно на сводке админки. Тяжёлые PDF можно отдавать по внешней ссылке |
| Vercel Hobby | — | — | **Не использовать:** запрещено коммерческое использование, включая рекламу своих продуктов |

**Фоновые задачи и e-mail** не нужны: сайт их не использует.
**Мониторинг ошибок:** логи функций — Netlify → Logs → Functions. Проверку доступности можно настроить бесплатным внешним монитором (любой uptime-сервис по адресу `/robots.txt`).
**Секреты** хранятся только в переменных окружения Netlify и в вашем `.env`, но не в коде.
**Бэкапы:** еженедельно `npm run backup` (см. руководство, раздел 10) + кратковременный откат в Neon.

## 3. Персональные данные ⚖️

Как устроен сайт сейчас:
- нет регистрации читателей, форм, комментариев, рассылок, аналитики и сторонних виджетов;
- записи читателей хранятся в localStorage их устройства, сервер их не получает;
- шрифты и скрипты загружаются только с самого сайта;
- в базе только контент и аккаунты администраторов (вы и ваша команда).

Что остаётся проверить с юристом:
- [ ] Хостинг-провайдер (Netlify, США) автоматически пишет IP-адреса в технические логи. Нужна оценка, считается ли это обработкой персональных данных оператором (ч. 5 ст. 18 и ст. 12 152-ФЗ), и нужно ли уведомление в Роскомнадзор.
- [ ] Финальный текст политики конфиденциальности (`/legal/privacy`) — по фактической схеме.
- [ ] Если позже появятся регистрация, формы, рассылка или приём оплаты на сайте, данные пользователей РФ придётся первично записывать в базы на территории РФ (с 1 июля 2025 года ч. 5 ст. 18 152-ФЗ). Это **отдельный этап с платным российским хостингом**; `Dockerfile` для него готов.

## 4. Продажи через соцсети ⚖️

Модель: автор (основатель) — правообладатель, ИП отца — продавец по лицензионному договору; продажа идёт на внешней площадке, на сайте только витрина и ссылка.

- [ ] Лицензионный договор автор → ИП (способы использования, территория, срок, вознаграждение). Исключительные права автоматически не передаются.
- [ ] Оферта или условия продажи для покупателей (`/legal/offer` — пока шаблон).
- [ ] Реальные реквизиты продавца в «Настройках сайта → Сведения о продавце». Не вводите вымышленные ИНН/ОГРНИП.
- [ ] Чеки по 54-ФЗ — через сервис, которым пользуется ИП.
- [ ] Данные покупателей, полученные в переписке (имя, телефон, e-mail), обрабатывает ИП как оператор. Нужны его политика и, при необходимости, уведомление РКН.
- [ ] Квалификация: продаются готовые информационные материалы для самостоятельного изучения, а не образовательные услуги. Её определяет фактическая деятельность, поэтому проверьте формулировки.
- [ ] Площадки: реклама в соцсетях, признанных в РФ экстремистскими (Instagram/Facebook), запрещена; используйте разрешённые (VK, Telegram и др.). Ссылки на сайте должны вести на страницы продавца.
- [ ] Только после этого: в админке у продукта указать «Ссылку для покупки» и статус «В продаже».

## 5. Контент и редактура

- [ ] Заменить или снять все демо-материалы (поиск в админке по пометке «демо»).
- [ ] Для каждого фактического материала: реальные источники, автор, дата обновления, статус «Проверено».
- [ ] Опросники: убедиться, что нигде нет слов «диагноз», «диагностика», «уровень расстройства»; если используется опубликованная шкала — лицензия и правила интерпретации.
- [ ] Книжная полка: только собственные аннотации; обложки — только с правами или нейтральные изображения.
- [ ] Фото основателя и история — реальные; образование указано точно (высшее юридическое; профпереподготовка «Социальная психология», НГУ, 504 ак. ч. — по предоставленным сведениям).
- [ ] Текст для чувствительных тем (Настройки → «Рекомендация для чувствительных тем») — проверить формулировку.
