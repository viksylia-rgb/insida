## 2. Хостинг: условия и лимиты GitHub Pages

- Бесплатно только для **публичного** репозитория: код и тексты видны на GitHub. Секретов в репозитории нет.
- Лимиты: сайт до 1 ГБ, около 100 ГБ трафика в месяц (мягкий лимит). Следите за размером фото.
- По правилам GitHub Pages нельзя использовать как бесплатный хостинг интернет-магазина или сайта, созданного в основном для коммерческих сделок. Журнал со ссылками «купить у продавца» на внешних площадках — допустимый вариант, но **витрина не должна становиться главной частью сайта**. Если продажи станут основной задачей, переходите на платный хостинг.
- Перепроверяйте условия перед запуском: правила сервисов меняются.

## 3. Персональные данные ⚖️

- Сайт не собирает данные читателей: нет регистрации, форм, cookie, аналитики и сторонних виджетов. Записи хранятся только в браузере читателя.
- [ ] Хостинг (GitHub, США) может вести технические логи с IP-адресами. Нужна оценка юриста, требуется ли что-то дополнительно по 152-ФЗ.
- [ ] Финальная редакция политики конфиденциальности (`content/pages/legal-privacy.md`).
- [ ] Если когда-нибудь появятся аккаунты, формы или оплата на сайте, это отдельный этап: сервер и база в РФ, уведомление РКН, документы.

## 4. Продажи через соцсети ⚖️

- [ ] Лицензионный договор: автор → ИП-продавец.
- [ ] Оферта (`content/pages/legal-offer.md`) и реальные реквизиты в «Настройках сайта → Сведения о продавце».
- [ ] Чеки по 54-ФЗ через сервис ИП.
- [ ] Данные покупателей из переписки обрабатывает ИП: политика ИП и, при необходимости, уведомление РКН.
- [ ] Разрешённые в РФ площадки (VK, Telegram и т.п.).
- [ ] Только после этого указывать у гайда ссылку для покупки и статус «в продаже».

## 5. Контент

- [ ] Заменить демо-материалы своими или снять с публикации.
- [ ] У каждого материала: реальные источники, автор, дата, статус проверки.
- [ ] В тестах нет слов «диагноз/диагностика».
- [ ] Книги: только собственные аннотации; обложки — только с правами.
- [ ] Проверить историю и миссию в «Настройках сайта».

## 6. Перед публикацией

- [ ] Во вкладке Actions зелёная галочка.
- [ ] Сайт проверен на телефоне (iOS Safari, Android Chrome) и компьютере, в светлой и тёмной теме.
