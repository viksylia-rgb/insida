# Архитектура INSIDA

## Принцип
Статический сайт без сервера, базы данных и аккаунтов.
- **Контент** — файлы в папке `content/` (Markdown и JSON), редактируются в Pages CMS или прямо на GitHub.
- **Сборка** — GitHub Actions (`.github/workflows/deploy.yml`) при каждом изменении: проверка контента и тесты → `next build` (статический экспорт в `out/`) → публикация на GitHub Pages.
- **Данные читателя** — только в его браузере (`src/lib/local-store.ts`): псевдоним, избранное, результаты тестов, ответы практик, прогресс программ. Экспорт/импорт файлом.
- **Тесты** считаются в браузере (`src/lib/scoring.ts`), **поиск** — тоже в браузере (`src/lib/search.ts`, понимает формы русских слов).
- **Cookie нет**, внешних скриптов/шрифтов/аналитики нет (CSP в `<meta>`).

## Карта страниц
`/` · `/library/` (фильтры и поиск) · `/library/<адрес>/` · `/topics/<тема>/` · `/tests/` · `/tests/<адрес>/` · `/practices/` · `/practices/<адрес>/` · `/programs/` · `/programs/<адрес>/` · `/programs/<адрес>/<урок>/` · `/guides/` · `/guides/<адрес>/` · `/books/` · `/search/` · `/account/` («Мои записи») · `/about/` · `/faq/` · `/contacts/` · `/legal/<документ>/` · `/sitemap.xml` · `/robots.txt`

## Контент (`content/`)
| Путь | Что | Формат |
|---|---|---|
| `articles/*.md` | статьи, термины, подборки | YAML-шапка + Markdown |
| `tests/*.json` | тесты: шкалы, вопросы, варианты с баллами, ветвление (`jumpTo`), правила результатов | JSON |
| `practices/*.md` | практики и поля для ответов | YAML-шапка + Markdown |
| `programs/*.json` | программы → модули → уроки | JSON |
| `books/*.json`, `guides/*.md` | книжная полка, гайды | JSON / Markdown |
| `pages/*.md` | «Об INSIDA», контакты, документы (`legal-*.md` → `/legal/*`) | Markdown |
| `settings.json`, `topics.json`, `faq.json` | настройки, темы, FAQ | JSON |

Адрес страницы = имя файла. Все файлы проверяются схемами в `src/lib/content.ts`: при ошибке сборка останавливается с сообщением, какой файл и какое поле исправить, и старая версия сайта продолжает работать.

## Будущее
Если понадобятся аккаунты, оплата на сайте или формы — потребуется сервер и база данных (для данных пользователей из РФ — на территории РФ). Предыдущая серверная версия сохранена в истории репозитория (коммит «INSIDA: первая версия сайта»).
