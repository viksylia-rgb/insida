# Архитектура INSIDA

## Принцип приватности
Читатель → браузер (localStorage): псевдоним, избранное, результаты тестов, ответы практик, прогресс программ.
Сервер → PostgreSQL: только опубликованный контент, файлы медиатеки, аккаунты редакции, журнал действий админов.
Тесты считаются в браузере (`src/lib/scoring.ts`), ответы не отправляются на сервер.

## Карта маршрутов
| Маршрут | Назначение | Рендеринг |
|---|---|---|
| `/` | Главная: hero, выбор редакции, «Что тебя волнует?», темы, форматы, новинки, практики, книги, об INSIDA | кэш 5 мин |
| `/library`, `/library/[slug]` | Каталог (фильтры, теги, поиск, страницы) и материал (источники, редактура, связанные) | динамика / ISR |
| `/topics/[slug]` | Все материалы темы | ISR |
| `/tests`, `/tests/[slug]` | Каталог и прохождение теста | динамика / ISR |
| `/practices`, `/practices/[slug]` | Каталог и практика с формой | динамика / ISR |
| `/programs`, `/programs/[slug]`, `/programs/[slug]/[lesson]` | Программы, уроки | кэш / ISR |
| `/guides`, `/guides/[slug]` | Бесплатные гайды и витрина платных («Скоро» / ссылка на продавца) | кэш / ISR |
| `/books` | Книжная полка по темам | кэш |
| `/search` | Поиск по всему сайту | динамика |
| `/account` | «Мои записи» (данные из браузера) | клиент |
| `/about`, `/faq`, `/contacts`, `/legal/[slug]` | Страницы и документы | кэш / ISR |
| `/login`, `/recover` | Вход и восстановление доступа редакции | динамика |
| `/admin/*` | Админ-панель (серверная проверка прав) | динамика, no-store |
| `/media/[id]` | Отдача файлов из БД (кэш 1 год) | функция |
| `/sitemap.xml`, `/robots.txt` | SEO | кэш 1 ч |

## Схема данных (src/server/schema.ts)
- **users** (только редакция), **sessions** (хеш токена), **recovery_codes** (HMAC), **rate_limits** (HMAC ключа), **audit_log**
- **topics**, **tags**, **articles** (+ `article_tags`; источники, автор, дата обновления, редакторская проверка, демо, SEO, `search_vector`)
- **tests** → **test_questions** → **test_options** (баллы по шкалам, переход к вопросу), **test_result_bands**
- **practices** (поля формы в JSON), **programs** → **program_modules** → **lessons**
- **books**, **products** (доступ free/paid, цена, статус «Скоро», файл, ссылка на покупку у продавца)
- **orders**, **order_items** — задел под будущий приём оплаты через продавца (сейчас не используются)
- **pages**, **faq_items**, **settings** (ключ → JSON), **media** (файл в bytea)

## Будущая оплата
Таблицы `orders`/`order_items` уже есть. Чтобы принимать оплату на сайте: подключить платёжного провайдера, работающего с ИП (с онлайн-чеками), добавить обработчик уведомлений об оплате и выдачу ключа доступа (`orders.access_key_hash`). Хранение данных покупателей потребует размещения базы в РФ и юридических документов. Переписывать сайт для этого не придётся: витрина, продукты и цены уже отделены.
