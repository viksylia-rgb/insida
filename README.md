# INSIDA

Русскоязычная платформа о психологии, самопознании и практиках самостоятельной рефлексии: библиотека с поиском, тесты для саморефлексии, практики, программы самостоятельного изучения, гайды, книжная полка и закрытая админ-панель.

**Ключевое решение:** сайт **не собирает данные читателей**. Регистрации для читателей нет. Избранное, псевдоним, результаты тестов, ответы в практиках и прогресс программ хранятся только в браузере читателя (localStorage) и не отправляются на сервер. В базе данных лежат только материалы и аккаунты редакции.

## Стек и почему он такой

| Часть | Выбор | Зачем |
|---|---|---|
| Фреймворк | **Next.js 16 (App Router) + TypeScript** | Серверный рендеринг и кэширование страниц (SEO, скорость), серверные действия для админки |
| База | **PostgreSQL** | Надёжно, бесплатно, встроенный полнотекстовый поиск с русской морфологией |
| ORM | **Drizzle ORM** | Типобезопасные запросы, понятные SQL-миграции, нет бинарных движков (проще деплой) |
| Авторизация | Своя: **Argon2id**, сессии в БД, httpOnly-cookie, коды восстановления | Без внешних платных сервисов и без e-mail |
| Поиск | PostgreSQL FTS + префиксный поиск + теги + фильтры | «Умный» поиск без платного AI |
| Шрифты | Cormorant Garamond + Manrope с собственного сервера (`@fontsource`) | Кириллица, без запросов к Google |
| Тесты | **Vitest** (модульные и на реальной БД) + **Playwright** (браузер, десктоп и телефон) | |
| Хостинг | **Netlify Free + Neon Free** | Бесплатно; на Netlify Free разрешено коммерческое использование |

Компромиссы: бесплатные тарифы имеют лимиты (см. [чек-лист](docs/LAUNCH_CHECKLIST.md)); картинки и PDF хранятся в базе (у Netlify нет постоянного диска), поэтому их размер ограничен; CSP разрешает inline-скрипты (нужно Next.js при статическом кэшировании).

## Быстрый старт (разработчику)

```bash
npm install
cp .env.example .env                 # заполните AUTH_SECRET
docker compose up -d                 # или свой PostgreSQL
npm run db:migrate                   # создать таблицы
npm run db:seed                      # демо-материалы (помечены как демо)
npm run admin:create                 # создать администратора (выдаст коды восстановления)
npm run dev                          # http://localhost:3000
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Режим разработки |
| `npm run build` / `npm start` | Сборка и запуск в боевом режиме |
| `npm run db:generate` | Создать миграцию после изменения `src/server/schema.ts` |
| `npm run db:migrate` | Применить миграции |
| `npm run db:seed` / `-- --force` | Демо-данные / перезаписать контент демо-данными |
| `npm run admin:create` | Создать администратора |
| `npm run admin:reset-password` | Сбросить пароль администратора из консоли |
| `npm test` | Модульные и интеграционные тесты (нужен `TEST_DATABASE_URL`) |
| `npm run test:e2e` | Браузерные тесты (сайт должен быть запущен, см. ниже) |
| `npm run typecheck` | Проверка типов |
| `npm run backup` / `npm run restore -- файл` | Резервная копия / восстановление БД |

### Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `DATABASE_URL` | да | Строка подключения PostgreSQL |
| `AUTH_SECRET` | да | Случайная строка ≥ 32 символов |
| `SITE_URL` | да в продакшене | Адрес сайта для SEO |
| `TEST_DATABASE_URL` | для тестов | Отдельная база, очищается тестами |
| `TRUSTED_PROXY_COUNT` | нет | `1` на Netlify/за nginx — для лимита попыток входа по IP |
| `DB_POOL_MAX` | нет | Размер пула (на бесплатном Neon — 3) |

## Безопасность (что сделано)

- Пароли — Argon2id (19 МиБ, 2 итерации); в БД хранится только SHA-256 токена сессии; cookie `__Host-`, httpOnly, Secure, SameSite=Lax; срок 30 дней со скользящим продлением.
- Защита от перебора: лимиты по имени и по IP (IP хранится только в виде HMAC), одинаковые ошибки и время ответа для неверного имени и пароля.
- Восстановление без e-mail: 8 одноразовых кодов (≈59 бит), после использования все сессии завершаются; плюс консольный сброс.
- Проверка прав в каждой операции на сервере (`assertAdmin`), CSRF — встроенная проверка Origin у server actions + SameSite.
- XSS: React-экранирование, markdown проходит через белый список `sanitize-html`, `javascript:`-ссылки удаляются.
- SQL-инъекции: только параметризованные запросы Drizzle.
- Загрузки: проверка типа по сигнатуре файла (не по расширению), лимиты размера, случайные имена, `nosniff` и `sandbox`-CSP при отдаче.
- Заголовки: CSP без внешних источников, HSTS, X-Frame-Options, Referrer-Policy, Permissions-Policy.
- Нет «админа по умолчанию» и общеизвестных паролей.

## Публикация

Подробно с картинками-шагами — в [руководстве владельца](docs/OWNER_GUIDE.md), раздел 7. Кратко: Neon (база) → GitHub (код) → Netlify (сайт) с переменными `DATABASE_URL`, `AUTH_SECRET`, `SITE_URL`, `TRUSTED_PROXY_COUNT=1`, `DB_POOL_MAX=3`. Сборка на Netlify сама применяет миграции (`netlify.toml`).

Для собственного сервера есть `Dockerfile` (режим `standalone`).

## Типичные ошибки

| Сообщение | Что делать |
|---|---|
| `Не задана переменная окружения DATABASE_URL` | Создайте `.env` из `.env.example` |
| `AUTH_SECRET не задана или слишком короткая` | Сгенерируйте секрет командой из `.env.example` |
| `ECONNREFUSED 127.0.0.1:5432` | База не запущена: `docker compose up -d` |
| `relation "…" does not exist` | Не применены миграции: `npm run db:migrate` |
| Сборка падает на этапе «Generating static pages» | Сборке нужна доступная база (`DATABASE_URL`) |
| `Слишком много попыток` при входе | Подождите 15 минут — сработала защита от перебора |
| Изменения не видны на сайте | Обычно обновляется сразу после сохранения; иначе — через 5 минут (кэш) |
| На Netlify «Site not available» | Кончились бесплатные кредиты месяца — см. чек-лист, раздел «Лимиты» |
