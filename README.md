# INSIDA — пространство для понимания себя

Журнал о психологии и самопознании: библиотека с поиском, тесты для саморефлексии, практики, программы самостоятельного изучения, гайды и книжная полка.

**Как устроено:** статический сайт на **GitHub Pages** — бесплатно, без сервера, без базы данных, **без аккаунтов и без cookie**. Избранное, результаты тестов, ответы в практиках и прогресс читателя хранятся только в его браузере. Тексты и материалы лежат в папке `content/` и редактируются в визуальном редакторе **Pages CMS**.

> 👩‍💻 Владельцу сайта: **[руководство владельца](docs/OWNER_GUIDE.md)** · **[чек-лист запуска](docs/LAUNCH_CHECKLIST.md)** · [архитектура](docs/ARCHITECTURE.md)

## Стек
Next.js 16 (статический экспорт) + TypeScript · контент в Markdown/JSON с проверкой схемами (zod) · шрифты Cormorant Garamond и Manrope с собственного хостинга · поиск и подсчёт тестов в браузере · Vitest + Playwright · GitHub Actions → GitHub Pages · Pages CMS для редактирования.

## Команды
| Команда | Что делает |
|---|---|
| `npm install` | Установить зависимости |
| `npm run dev` | Режим разработки: http://localhost:3000 |
| `npm test` | Проверка контента (все файлы, правила тестов, ссылки) и логики (подсчёт, поиск, XSS, хранение записей) |
| `npm run build` | Собрать сайт в папку `out/` |
| `npm run preview` | Открыть собранный сайт локально |
| `npm run test:e2e` | Проверки в браузере (десктоп и телефон) — сайт должен быть запущен |
| `npm run typecheck` | Проверка типов |

Переменные (необязательно, на GitHub Pages задаются автоматически): `NEXT_PUBLIC_BASE_PATH` (подпапка, например `/insida`), `NEXT_PUBLIC_SITE_URL` (полный адрес сайта).

## Публикация
Любое изменение в ветке `main` (в том числе сохранение в Pages CMS) запускает `.github/workflows/deploy.yml`: тесты → сборка → публикация. Если в контенте ошибка, публикация останавливается, а предыдущая версия сайта продолжает работать. Ошибку видно во вкладке **Actions** репозитория.

## Структура
```
content/          тексты и материалы сайта (редактируются в Pages CMS)
public/images/    фото (uploads/ — загруженные через редактор)
public/files/     PDF для скачивания
src/app/          страницы
src/components/   интерфейс
src/lib/          content.ts (загрузка и проверка контента), scoring.ts (тесты),
                  search.ts (поиск), local-store.ts (записи читателя), markdown.ts (безопасный HTML)
src/styles/tokens.css   цвета, шрифты, отступы — менять дизайн здесь
.pages.yml        настройки редактора Pages CMS
```

## Безопасность и приватность
- Нет аккаунтов, паролей, форм, cookie, аналитики и сторонних скриптов; CSP запрещает внешние источники.
- Записи читателей не покидают браузер; есть экспорт, импорт и полное удаление.
- Markdown проходит через белый список тегов (защита от XSS); внешние ссылки — `noopener nofollow`.
- В репозитории нет секретов — он может быть публичным.

## Типичные ошибки
| Что видно | Что делать |
|---|---|
| В Actions красный крестик «Проверка контента» | Откройте лог: там написано, какой файл и какое поле исправить |
| `адрес … латиницей` | Адрес (slug) — только латиница в нижнем регистре и дефисы |
| `тема «…» не найдена` | Укажите адрес существующей темы из раздела «Темы» |
| Изменения не видны | Публикация занимает 2–4 минуты; обновите страницу без кэша (Ctrl+F5) |
